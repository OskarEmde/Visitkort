# Oskar Emde – Portfolio

Personlig portfolio til multimediedesign. Siden viser en showreel, en præsentation, projekter inddelt i spil/hjemmesider/andet arbejde og en kontaktside.

## Teknologier
HTML5, CSS3 (Flexbox/Grid, responsive media queries), JavaScript med Three.js og GLTFLoader til 3D-karrusellen, PHP til kontaktformularen.

## Designvalg
Fantasy-inspireret visuelt univers med mørkegrønne nuancer, gulddetaljer og gotisk typografi. Projekterne er opdelt i kategorier, så man kan finde dem fra både navigation og forside.

## Lokalt
Åbn projektet via lokal webserver (ikke kun file://), så JavaScript-modulerne kan indlæses korrekt. Behold eksisterende assets i `assets/images/`, `assets/video/` og eventuelle 3D-modelfiler.

## Kontaktformular
Konfigurér `$recipient` i `contact.php` til en rigtig adresse. Formularen skal testes på PHP-hosting med fungerende mailafsendelse. Sociale profillinks, der står som pladsholdere, skal udfyldes.
